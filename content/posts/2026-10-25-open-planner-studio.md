[Open Planner Studio](https://www.open-aec.com/open-planner-studio/) is an open source construction planning application built around Gantt charts, Work Breakdown Structures, and automatic Critical Path Method calculations with float analysis. Tasks can be edited in a hierarchical table or on an interactive timeline, with support for labour, equipment, subcontractors, holidays, inspection points, and construction phases.

Planning files are saved directly as IFC 4.3, and tasks can be linked to elements in an IFC building model for 4D construction sequencing. The application also includes an IFC code editor, reporting with live print preview, and an interface available in six languages.

Open Planner Studio is built with Tauri, Rust, React, and TypeScript, with desktop downloads for Windows, macOS, and Linux. It can also be [tried online in a web browser](https://open-planner-studio.open-aec.com/), and the project is seeking feedback from planners, project managers, and BIM coordinators.
